# 🎨 Design

## Overview
The system is designed to be simple, fast, and easy to use.

---

## UI Components
- Input field
- Ask button
- Output display box

---

## UX Goals
- Minimal interface
- Fast interaction
- Easy to understand

---

## User Flow
1. User types query  
2. Clicks Ask  
3. Response is shown  
4. Can request article  

---

## Design Decisions
- Plain HTML + JS (fast development)
- No frameworks (simplicity)
- Focus on functionality

---

## Limitations
- No advanced UI
- No chat history UI
- No mobile optimization

---

## Future Improvements
- React UI
- Chat layout
- Loading animations
